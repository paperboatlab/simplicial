string
======

Text on the wires: formatting, joining, splitting, searching and changing case. ``format`` makes
its inputs from the placeholders in its template (``"{first} {last}"``), ``concat`` joins any
values as text, and ``text_test`` is a magic block: a 1 or 0 in its signal form, a ``yes``/``no``
branch in its step form.
