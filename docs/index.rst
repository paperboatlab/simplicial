Simplicial
==========

Simplicial is visual flow, station and block-diagram simulation: a C++20 engine that runs stations,
and a page that sets them up, wires them and watches them run. Stations are written in C++, Python or
Julia; optional toolkits add blocks.

Simplicial is being rebuilt on the new platform. Until this manual is filled in, the previous
version's manual is the reference: `paperboat-legacy docs/api
<https://github.com/paperboatlab/paperboat-legacy/tree/dev/docs/api>`_.
